# Лунный атлас

Интерактивная карта видимой стороны Луны: 60 объектов с латинскими названиями,
русскими эквивалентами, размерами и фактами. Кратеры нанесены в истинном масштабе
с учётом ракурса у края диска; тень рассчитывается по настоящей фазе на текущий момент.

**https://andrewivlev.github.io/**

## Что внутри

- **Проекция** — ортографическая, R = 1737 км, север сверху, восток справа
  (ориентация как в бинокль без призмы-перевёртыша).
- **Фаза** — усечённые ряды ELP2000/VSOP87 (Meeus, гл. 25 и 47), ошибка по
  эклиптической долготе < 0.1°. Ведущая величина — элонгация Луна–Солнце:
  0° новолуние, 180° полнолуние. Терминатор, освещённость и «возраст в сутках»
  выводятся из неё.
- **Ползунок** — отматывает любую ночь синодического цикла.
- **«Лучший контраст сегодня»** — объекты в пределах 18° от терминатора,
  где солнце стоит низко и рельеф читается лучше всего.
- **Фильтр 10×** — скрывает то, что в бинокль всё равно не разглядеть
  (предел по деталям ≈ 20 км).

## Стек

Никакого. Один статический HTML-файл, 54 КБ: CSS, JS, данные и генерация SVG —
всё инлайном. Ни одного сетевого запроса, ни одной зависимости, ни шага сборки.
Шрифты — системные стеки, поэтому работает офлайн и без FOUT.

## Данные

Координаты и размеры — IAU / USGS Gazetteer of Planetary Nomenclature.
Очертания морей схематичны: заданы вручную эллипсами в проекции, а не
оцифрованы с фотометрии.
